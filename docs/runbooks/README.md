# Profusion Runbooks

Operational runbooks are split by use case:

- `daily-operations.md` — normal queue and publishing workflow
- `failure-recovery.md` — retry and diagnostic workflow
- `handoff-checklist.md` — fresh context / agent handoff
- `release-checklist.md` — local verification before milestone handoff
- `m8_gtm_n8n_receipt_harness.md` — P0 fixture-backed Customer Trust Triage
  Receipt harness
- `aice_workflow_receipt_validator.md` — local-only validator for one completed
  AICE receipt packet
- `path_c_turnkey_reproduction.md` — fresh-clone P0 bootstrap and smoke path

Legacy quick-start notes remain in the project `README.md`.
